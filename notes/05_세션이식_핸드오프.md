# 세션 이식용 핸드오프 (2026-10-08 기준)

다른 세션에서 이어 작업할 때 이 문서를 먼저 읽는다. 상세 내용은 각 노트를 참조한다.

## 1. 프로젝트 개요
- **목적:** 오송 신약개발지원센터(KBIOHEALTH) 연구원 대상 세미나 발표자료 제작. 발표자는 타이탄바이오 이윤범(v1 표지 기준).
- **주제:** NGS 기반 외래성 바이러스(adventitious virus) 검출. '외래성'은 임상 용어가 아니라 **생물의약품 규제 용어**이며, 기준점은 환자가 아니라 세포기질 유전체다(ICH Q5A(R2) 외래성 대 내인성).
- **분량:** 본 발표 40분 이내. 청중은 부정시험 분야의 실무 전문가이므로 서술은 겸손하게, 출처가 확인된 내용만 쓴다.
- **저장소:** `lyb2106/weather_test`, 브랜치 `claude/inspiring-hamilton-hvu81g`. 기존 weather_test 프로젝트는 폐기되어 `old/`에 보관되어 있다(건드리지 않는다).

## 2. 확정된 방침
1. 사례 논문 13편(`notes/02`)은 **하나도 빼지 않는다.** 편당 설명을 줄이고 주제별로 묶는다.
2. NGS의 검출 성능을 보여 주던 참조 논문 **Grard 2012 (Bas-Congo virus, PMID 23028323)** 는 본 발표에서 빼고 **Supplementary 1장**으로만 둔다.
3. 목차: ① 인트로(ICH 최신 권고, 국제 인허가 동향, Rotarix, 대체시험법, 마지막 장에 외래성 바이러스 정의) → ② 부정시험(출처 기반, 겸손한 서술) → ③ NGS 원리와 in-silico 워크플로(host removal 필수) → ④ 사례 13편 주제별.
4. **슬라이드 규칙:** 1슬라이드 1메시지. 헤드라인 1줄과 명사형 키워드 3개로만 구성하고 줄글은 금지한다. 제목은 짧게 쓴다. 모든 슬라이드가 같은 글머리 기호로 끝나지 않도록 수치 중심, 문장 하나 강조, 비교표, 타임라인 등으로 레이아웃을 바꾼다.
5. **디자인 규칙:** 메인 다크 네이비 `#000080`, 강조 오렌지 `#FFA500` 한 가지만 사용. 배경은 흰색 또는 연회색. 스톡 아이콘과 3D 이미지는 금지하고, 논문 첫 페이지, 대표 figure, 선형 그래프, 비교표를 우선한다.
6. **버전 관리 필수:** 현재 작업본은 `slides/`에 하나만 둔다. 새 버전을 만들면 이전 버전은 `slides/archive/`로 옮기고 덮어쓰지 않는다. 변경은 `slides/CHANGELOG.md`에 기록하고 커밋 메시지에 버전 번호를 쓴다. **v1부터는 사용자 편집본이 기준**이므로 `archive/build_v0.js`로 다시 생성하지 않고 PPTX를 직접 고친다.
7. 사용자 선호: 과학적이고 논리적인 문체, 의학 리뷰 논문 수준. 모든 주장은 사실 확인을 거치고 중요한 것은 reference와 링크를 명기한다.

## 4. 버전 이력
- **v0 (자동 생성, 47장):** 콘티를 바탕으로 pptxgenjs로 생성. 논문 figure 자리는 점선 틀로 비어 있다.
- **v1 (사용자 편집, 46장):** 표지 제목을 "NGS 기반 외래성 바이러스 검출"로 바꾸고 "오송 신약개발지원센터"와 발표자명을 추가. "반복되는 오염" 슬라이드 삭제. Rotarix 헤드라인을 "출하시험 통과 후 PCV1 검출"로 변경. ICH 슬라이드의 문구를 "Face-to-Face 비교 불요"로 변경.
- **v2 (Claude 수정, 46장):** "Face-to-Face"를 ICH 원문 용어 **"Head-to-head 비교 불요"** 로 수정. 텍스트 비교상 유일한 변경이다.

## 5. 슬라이드 구성 요약 (v0 기준, v1·v2에서 일부 변경)
- 인트로: 오염 사건 연표(v1에서 삭제) → Rotarix 2010 → ICH Q5A(R2) → 이미 현행 규제(연표) → 무엇이 대체되나(비교표) → 외래성의 기준점
- 부정시험: 단계별 시험 → In vitro → In vivo → 항체생산시험·PCR → 내인성 → 전통법의 세 가지 한계
- NGS: 질문이 다르다 → 라이브러리 → 클러스터 → SBS → 무엇을 시퀀싱할 것인가 → 대조군 → In-silico 파이프라인 → 호스트 = 생산세포주 → 지우면 안 되는 것 → DB 선택 → 판정과 확증
- 사례: 지도 → 원료(Gagnieur 2014, Zhang 2022) → 발현을 본다(Onions 2011) → 없음의 증명(Shabram 2014) → 통과 ≠ 무바이러스(Ma 2014) → 서열 ≠ 감염성(Geisler 2016) → 한 번에 보인 것(Victoria 2010) → 전통법도 잡았다(Kerr 2010) → 설계로 막는다(Mascarenhas 2017) → 동물시험 5/9(Beurdeley-Fehlbaum 2023) → 1 copy/assay(Hirai 2024) → 이미 교체했다(Alston 2025) → 합의에 이르기까지(Khan 2025)
- 정리, Supplementary(Bas-Congo, In vivo 상세, References)
- 발표자 노트에 슬라이드별 요지, 근거, ⚠ 확인 항목이 들어 있다(v0 기준. v1·v2에서 보존 여부는 확인하지 않았다).

## 7. 미해결·원문 확인 필요 항목
이 환경에서는 PubMed, PMC, 출판사, ICH·FDA·EMA·EDQM·WHO·Illumina 사이트에 접속할 수 없어 모든 검증이 **검색엔진 색인의 초록과 공식 페이지 발췌** 기준이다. 아래는 원문 PDF 대조 전에는 슬라이드에 확정 표기하면 안 된다.
- **수치:** Gagnieur 2014의 바이러스 read 비율 0.002–22.7%와 통용 BVDV 프라이머 불일치, Geisler 2016의 유전자 자리 4곳과 M ORF 없음, Bas-Congo의 아미노산 동일성 34% 미만(Supplementary에 이미 게재됨, 출처 줄에 "원문 대조 필요" 표기), Mascarenhas 2017의 "catastrophic" 인용과 생산성 유지, Alston 2025의 회사 협업과 정면 비교 생략, Hirai 2024의 교차오염 언급
- **규제 문서:** ICH Q5A(R2) §3.2.5.2 인용문과 절 제목의 글자 단위 대조, Table 1의 셀 값, 지시세포 관찰 기간(28일)의 출처, FDA 2010 가이던스의 동물 수와 관찰 일수, Ph. Eur. 5.2.3·2.6.16의 삭제 항목
- **국내:** 식약처의 ICH Q5A(R2) 시행 여부와 일자, NGS 정보집(2021) 발간일, 가이드라인(2010) 등록일
- **PMID 미확인:** IABS 2차 보고, Charlebois 2020, Simonyan 2016. **추정:** 4차 보고 40945333, Khan 2017 28932815, Rupp 2018 29704459
- **FDA Rotarix 원 보도자료 URL:** 현재는 보도 기사 경유로만 확인
- **slides 삽입 대기:** 논문 첫 페이지와 대표 figure 캡처, ICH Table 1, FDA 2010 in vivo 표. 로컬에서 캡처가 필요하다.
- **v1 이후 상태 미점검:** v1 편집 후의 레이아웃과 발표자 노트는 시각 검수를 하지 않았다.

## 9. 기술 메모
- PPTX 직접 편집: 압축을 풀어 `ppt/slides/slideN.xml`을 수정하고 다시 zip한 뒤 `validate.py`로 검증하는 방식을 썼다.
- v0는 `slides/archive/build_v0.js`(pptxgenjs, 16:9 와이드 13.33×7.5in, 글꼴 맑은 고딕)로 생성했다.
- 렌더링 확인은 LibreOffice Impress와 PyMuPDF로 했고, 한글 글꼴이 대체되므로 줄바꿈 위치는 실제 PowerPoint와 다를 수 있다.
- git 태그는 이 환경의 네트워크 제한으로 원격에 올라가지 않아 쓰지 않는다. 버전은 파일명, archive, CHANGELOG로 관리한다.
- 커밋 메시지 끝에는 세션 안내의 Co-Authored-By와 Claude-Session 줄을 붙인다.
